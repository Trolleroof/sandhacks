# Local Model Files

Place your local inference model files here.

Expected defaults (see `config/camera_params.yaml`):

- `mobilenet_ssd.caffemodel`
- `mobilenet_ssd.prototxt`
- `mobilenet_ssd.labels` (provided)

If you use a different model, update the paths in
`ros2/src/oak_camera/config/camera_params.yaml`.
