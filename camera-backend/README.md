# Luxonis Camera Setup

## Prerequisites
Install DepthAI v3:
```bash
pip install depthai
```

## Usage

### 1. Test Camera Connection
```bash
python camera_test.py
```

### 2. Basic Camera Setup
```bash
python basic_camera.py
```

### 3. Camera with Display
```bash
python camera_display.py
```

## Dependencies
- depthai (Luxonis DepthAI SDK)
- opencv-python (for display)
- numpy

Install dependencies:
```bash
pip install depthai opencv-python numpy
```
